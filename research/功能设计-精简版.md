# 睡眠助手 · 功能设计（精简版）

> 从 37 项砍到 8 项。
> 两个筛子：**证据必须 A 级**｜**打开就能用**（不注册、不连续记录、不多步流程）

---

## 一句话

**打开就算，算完就走。**

不要求用户记录、不要求登录、不搞流程。每个功能都是「输 1～2 个值 → 立刻出结论」。

---

## 一、保留的 8 项

### 核心（首页，一屏）

**1. 今晚几点睡**
- 输入：明天几点起
- 输出：**3 个候选**（6 周期 9h / 5 周期 7.5h / 4 周期 6h）
- 5 周期标「推荐」
- 默认参数直接算，**不需要先填任何东西**
- 「周期长度」「入睡潜伏期」折叠在一个「微调」里，默认 90 / 15，想改的人才点

> 为什么只给 3 个：6 个候选要用户自己判断，是负担。4/5/6 覆盖 99% 场景。

### 工具（4 张卡）

**2. 咖啡因截止线**
- 选饮品（下拉，带 mg 值）→ 选喝的几点 → 选几点睡
- 输出：「到 23:30 还有约 40 mg 在体内，影响较小 / 建议再提前 2 小时」
- 一句话结论，加一条衰减曲线

**3. 小睡几分**
- 就两档：**20 分钟**（清爽）/ **26 分钟**（NASA）
- 点一下 → 显示该几点醒
- 砍掉 60/90 档，那两档醒来容易发懵

**4. 熬夜急救**
- **一屏 6 条卡片**，不是流程
- 当晚提前睡 / 早上见光 / 午后小睡 26 分 / 咖啡因 14 点后停 / 别用酒 / 别指望周末补
- 每张卡右下角一个「A」标

**5. 泡澡提醒**
- 就一句话 + 一个计时器：「睡前 90 分钟泡 10–20 分钟热水澡，平均快 10 分钟入睡」
- 点「现在开始」→ 10 分钟倒计时

### 内容（2 块）

**6. 认知洗牌**
- 一个按钮「开始」，屏幕逐字显示（字 → 联想词，每 8 秒自动换）
- 用户什么都不用做，看着就行
- 睡着就睡着了，不用管它

**7. 依据与误区**（一页，折叠展开）
- 上半：7 条误区（点开看真相）
- 下半：核心结论 + 出处

**误区 7 条**（都是 A 级证据，传播力最强）：
1. 睡眠必须是 90 分钟的整数倍 → 周期 70–120，中位数 96
2. 周末睡懒觉能补回来 → 一晚补不回；还会造成社会时差
3. 早睡一小时就能多睡 → 撞进禁睡区，反而更难睡
4. 我喝咖啡照样睡 → 主观感觉不可靠，客观少睡 1 小时
5. 睡前喝酒助眠 → 低剂量就减少 REM
6. 手环测的睡眠分期很准 → 消费级准确率仅 70–80%
7. 蓝光眼镜能改善睡眠 → Cochrane 2023：证据极低

## 二、砍掉的 29 项（合并为 16 条列出）

| 砍掉 | 原因 |
|---|---|
| 睡眠日记（9 项标准字段） | 每天填 9 项，太重；你是自己用不是给医生看 |
| 睡眠负债账本 | 要连续记录好几天才有意义 |
| 社会时差 | 要输入工作日+休息日两组数据 |
| 趋势图表 / 周复盘 | 依赖历史数据积累 |
| 睡眠效率闭环（SE 调窗口） | 本质是 CBT-I 治疗手段，越界 |
| 呼吸引导（4-7-8） | 证据只有 B/C，且混乱 |
| 光照提醒 | 要定位权限、要每日推送 |
| 卧室温度四段协议 | 四段温控太复杂，一句话就够（见下） |
| 睡眠卫生 daily 打卡 | 又一个每日负担 |
| 数据导出 / 分享卡 | 自己用不上 |
| 4 步引导 onboarding | 直接删，打开就能算 |
| 智能闹钟 | 网页做不到真正唤醒 |
| 睡前降速流水线（T-120 到 T-0 六段） | 太像待办清单，砍成 5 里的那一条 |
| SRI / 时差调整 / 伴侣对齐 / 轮班模式 | 场景太小众 |
| 自评问卷 / 个性化洞察 | 要数据积累 |
| 白噪音 / 冥想音频 / 睡眠监测 / 阶段图 / 睡眠总分 / 连胜 | 见第四节红线 |

> 卧室温度那一条**不单独做功能**，就写在首页底部一行小字：**「卧室 18–20℃，脚别捂太严。」** 一句话交付，不占流程。

## 四、红线（这些坚决不做）

| 不做 | 一句话原因 |
|---|---|
| 睡眠监测（麦克风/手环） | 网页做不到；手机方案精度只有 70–80% |
| 白噪音 / 冥想音频 | 红海，且证据只有 B/C |
| 睡眠阶段图 | 没有真传感器就是在编数据 |
| **睡眠总分** | 引发「睡眠表现焦虑」，科学上也站不住 |
| **连胜 / 打卡天数** | 断一次就让人想卸载，是这类产品最大的流失源 |
| 要求注册 / 登录 | 自己用的工具，不需要 |
| 每日提醒推送 | 又多一个负担 |
| 医疗建议 | 越界；长期失眠该看医生 |

## 五、8 项的证据等级

| # | 功能 | 等级 | 出处 |
|---|---|---|---|
| 1 | 今晚几点睡 | **A** | AASM/SRS 2015 共识；Ohayon 2004（潜伏期）；周期中位数 96 的 PSG 回顾研究 |
| 2 | 咖啡因截止线 | **A** | Drake C et al. *J Clin Sleep Med* 2013 |
| 3 | 小睡 20/26 | **B** | Rosekind MR et al. NASA TM 1994 / *J Sleep Res* 1995 |
| 4 | 熬夜急救 | **A** | Van Dongen 2003 *Sleep*；Banks 2010 *Sleep* |
| 5 | 泡澡提醒 | **A** | Haghayegh S et al. *Sleep Med Rev* 2019;46:124-135 |
| 6 | 认知洗牌 | **B** | Beaudoin LP et al. 2019；Lemyre A et al. *Sleep Med Rev* 2020 |
| 7 | 7 条误区 | **A** | 见 `睡眠科学权威依据库.md` 第 7 节引用清单 |

8 项里 6 项 A 级、2 项 B 级（都是该领域最经典的单项研究）。**没有 C 级功能。**

## 六、实现量

纯 HTML + CSS + JS，一个 `index.html` 加一个 `sleep-core.js`（已写好）。

- 计算逻辑：已有
- 咖啡因曲线：Canvas 画一条指数衰减线，20 行
- 认知洗牌：一个词库数组 + `setInterval`
- 泡澡倒计时：`setInterval` + 一行文案
- 排版：移动优先，深色为主（夜间看不刺眼）

**没有后端、没有构建、没有依赖。** 写完直接推 GitHub Pages。

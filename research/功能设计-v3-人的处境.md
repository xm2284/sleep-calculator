# 睡眠助手 · 重新设计（按人的实际处境推演）

> 不是功能清单，是从「一个人此刻在干什么」倒推

---

## 一、前几版错在哪

一句话：**我在做功能，你在做使用。**

| 错的 | 为什么错 |
|---|---|
| 咖啡因截止线 | 躺着的人不会先想「我喝的是什么、几点喝的」再去看结果 |
| 小睡几分 | 要点一下、要选时长 |
| 泡澡提醒 | 泡澡是「想起来才做」的事，不是「被提醒就做」的事。提醒了也不会去 |
| 认知洗牌 | 躺在床上的人不会点一个「开始」按钮，然后盯着屏幕看词 |
| 4 步引导 | 打开网站还要填问卷 |

**共同病根：都要求用户主动做一个动作。**

> ### 睡前场景的唯一铁律
> **用户不会点任何东西。**
> 只能给他「看的」，不能给他「点的」。

这条铁律一排，前面一半功能自动出局。

## 二、三个真实时刻

### 时刻 1 · 晚上 20:14，坐在沙发上
他在想：今晚想 7 点起，那我几点得睡？
**答案：一个时间点。**

### 时刻 2 · 23:52，已经躺下了，手机还举在手上
他眼睛半闭，脑子还热着。
他不想看任何东西，只想确认一件事：**现在睡，还来得及吗？**
**答案：一句话，别让我选。**

### 时刻 3 · 凌晨 01:40，一边自责一边还醒着
他知道自己搞砸了。这时候给他科普、给建议，都是二次伤害。
他真正要的是：**有人替他下个命令，然后把这件事翻过去。**
**答案：一句「现在立刻去睡」，加上明天怎么办的具体安排。**

---

## 三、三个时刻其实是同一个问题

```
现在几点  +  明早几点起  →  一个答案
```

不需要输入饮品、不需要选时长、不需要点按钮。
**只需要一件事：打开就看到答案。**

---

## 四、所以只做一个东西：一屏，四态

页面根据**当前时间**自动切换文案。用户什么都不用做。

### 状态 A ｜ 还早（距就寝 > 60 分钟）

```
现在 20:14

今晚 23:00 睡，明早 07:00 起
你能睡满 5 个周期 · 7 小时 30 分

距 23:00 还有 2 小时 46 分
```

底下跟一行小字（当前时段唯一有用的那条，不是清单）：

```
▸ 现在起别再喝咖啡了
```
（20:14 这个点，唯一能改变今晚的事就是这一条。别的都太早。）

### 状态 B ｜ 该准备了（距就寝 ≤ 60 分钟）

```
现在 22:12

48 分钟后该睡了

关灯，把手机放到伸手够不到的地方。
明早 07:00 起，睡满 5 个周期。
```

### 状态 C ｜ 已经晚了（过了目标就寝）

```
现在 00:38

比目标晚了 1 小时 38 分
现在立刻睡，7:00 起还能睡 6 小时 22 分（4.2 个周期）

别再算了，直接睡。
```

### 状态 D ｜ 凌晨还没睡（判断 + 止损）

```
现在 02:47

这个点睡，7:00 起只有 4 小时 13 分。
今晚的账欠下了，补不回来。

现在的唯一正确操作：关掉所有屏幕，去睡。

明天这样安排：
· 闹钟照旧 7:00，不要赖床
· 中午 13:00 前小睡 20 分钟，不要更久更晚
· 咖啡只在 14:00 前喝
· 晚上比平时早 1 小时躺下
```

**状态 D 是唯一允许有「多条内容」的地方**——因为这时候人是清醒的、在找答案的，能读得进去。

## 五、唯一需要设的东西：你几点起

页面右上角一个小齿轮，点开就一个输入框：**明早几点起**（默认 07:00）。

设一次，存本地，以后永远不用再管。

**除此之外没有任何设置。** 今天想 6:30 起，点一下改掉就行。

## 六、熬夜之后要「具体」——具体到钟点

不说「早点睡」「注意补觉」这种废话。全部给数字：

| 什么时候 | 做什么 | 为什么 |
|---|---|---|
| 明早 | 闹钟**照旧**，不许赖床 | 起床时间是锚点，一乱全乱 |
| 13:00 前 | 小睡 **20 分钟**，不超过 | 再晚会偷今晚的睡眠；再久会醒来发懵 |
| 14:00 后 | 咖啡**停** | 半衰期 5–6 小时，睡前 6 小时喝仍少睡 1 小时 |
| 今晚 | 比平时**早 1 小时**躺下 | 分期还债，一晚还太多了反而睡不着 |
| 今晚 | **不喝酒** | 酒精只是让你快点晕，REM 照减 |
| 这个周末 | **别睡到中午** | 起床时间差超过 1 小时就是社会时差，周一更惨 |

## 七、砍掉的和为什么

| 砍 | 为什么 |
|---|---|
| 咖啡因截止线（选饮品/选时间） | 场景不存在。真想控咖啡因的人，记不住也不会去算 |
| 小睡几分（20/26 两档按钮） | 直接写进状态 D 的「20 分钟」，不用做成功能 |
| 泡澡提醒 + 倒计时 | 没人会被一个网页提醒去泡澡 |
| 认知洗牌引导器 | 躺床上不会点开始按钮。真失眠的人对「技巧」还有抵触 |
| 咖啡因衰减曲线 | 曲线是给分析师看的，床上的人只要「还能不能喝」 |
| 3 个候选时间（9h/7.5h/6h） | 还是要他选。直接给**一个**最佳答案 |
| 7 条误区专区 | 不是睡前的需求。真要做，放到页脚一个小链接，别占主屏 |
| 微调（周期长度/潜伏期） | 藏在齿轮里，默认值不动 |
| 熬夜急救（6 张卡片） | 保留内容，但**改成状态 D 里的具体安排**，不单独做页面 |

## 八、最终：一个页面，四段文案，一个输入框

```
┌────────────────────────────┐
│                        ⚙ 07:00 │
│                            │
│         20:14              │   ← 当前时间，最大字号
│                            │
│   今晚 23:00 睡            │
│   明早 07:00 起            │
│   睡满 5 个周期 · 7 小时 30 分 │
│                            │
│   距 23:00 还有 2 小时 46 分  │
│                            │
│ ─────────────────────────  │
│ ▸ 现在起别再喝咖啡了          │
└────────────────────────────┘
```

**没有 tab，没有卡片，没有按钮，没有浮层。**

往下滚，只有一块：**「熬夜了怎么办」**（就是上面第六节那张表，做折叠）。

就这些。

---

## 九、为什么这才是对的

1. **零操作**：躺下也能用，一个手指都不用动
2. **零选择**：不给三个候选让人挑，直接给一个答案
3. **零知识负担**：不用理解什么是睡眠周期，只要知道「几点睡」
4. **会说人话**：状态 D 那句「别再算了，直接睡」，是在替用户踩刹车——这是唯一能真正改变行为的东西
5. **数字具体**：「7 小时 30 分」比「7.5 小时」有用，「20 分钟，13:00 前」比「适当小睡」有用

# 几点睡 · 睡眠周期计算器

一个零依赖、零后端的单文件睡眠计算器。输入「明早几点起」或「今晚几点上床」，按 90 分钟睡眠周期，一次算清你该几点睡、该几点起。

## 功能

- **该几点睡**：按明早闹钟倒推三个就寝时刻（6/5/4 周期）
- **该几点起**：按今晚 上床时间顺推三个起床时刻，一键设闹钟
- **已经躺下了？按现在算**：深夜打开自动按当前时间算
- **闹钟对齐**：结果直接跳系统闹钟（Android intent / iOS 快捷指令）
- **微调**：躺下到睡着时长、睡眠周期长度（默认 90，可 70–120）
- **熬夜急救**：带具体钟点的恢复指引
- 本地存储、无账号、无追踪

## 为什么是 90 分钟

睡眠以约 90 分钟为周期循环（浅睡→深睡→REM）。在周期结束的浅睡段醒来，比在深睡中被闹钟硬拽醒更轻松。90 分钟是人群均值，个体实际在 70–120 分钟之间——所以微调里可以改。

科学依据详见 [`research/睡眠科学权威依据库.md`](research/睡眠科学权威依据库.md)。
